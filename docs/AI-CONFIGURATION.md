# AI 接口配置

开始菜单的 **配置 AI** 会打开当前使用者的配置文件。三个字段均由使用者自行填写：

| 字段 | 填写内容 |
| --- | --- |
| `ai.baseUrl` | 服务商的 OpenAI 兼容接口基础地址或聊天接口地址 |
| `ai.model` | 服务商提供的模型名称 |
| `ai.apiKey` | 使用者自己的 API 密钥 |

默认样例为 `app/settings.example.json`，不附带任何真实地址、路由或密钥。保存后，从开始菜单关闭背景并重新打开。

配置文件保存在 `%LOCALAPPDATA%\CodexFolia\settings.json`，与项目源码分开。仓库忽略所有实际 `settings.json`、`.env` 和登录数据目录。应用只读取自己的配置，并将 AI 配置限制在播放器后台进程中。

如果使用自建的 OpenAI 兼容服务，按该服务要求填写接口地址、模型和鉴权值。未配置或缺少字段时，AI 按钮会提示先完成配置；其他播放器功能继续可用。
